# docs_for_players/

> Cartella che ospita la **documentazione destinata ai giocatori** del server (non al team dev).

## Filosofia

I documenti qui sono scritti pensando al **giocatore finale**, non allo sviluppatore:
- linguaggio piano e accogliente, non tecnico
- istruzioni step-by-step con screenshot dove utile
- focus sull'esperienza, non sull'implementazione
- italiano semplice

Tutto ciò che è meta-progettuale (visione, decisioni, modlist tecnica) resta nella root del repo e **non** viene esposto qui.

## Contenuto previsto

| File | Cosa è |
|---|---|
| `INSTALL_GUIDE.md` | Come installare il client del server, passo per passo |
| `FIRST_LOGIN.md` | Cosa fare al primo accesso (creazione personaggio, primi minuti di gioco) |
| `SERVER_RULES.md` | Regole del server (versione official, sincronizzata col canale Discord) |
| `RP_GUIDE.md` | Guida all'interpretazione del personaggio (etichetta RP, do's and don'ts) |
| `TROUBLESHOOTING.md` | Risoluzione dei problemi più comuni (crash all'avvio, errori di connessione STR, ecc.) |
| `FAQ.md` | Domande frequenti |
| `CONTACTS.md` | Come contattare lo staff per problemi |

## Discord vs questa cartella

I documenti qui sono la **fonte canonica** delle informazioni user-facing. Discord ospita la versione "viva" (canali di discussione, supporto), e linka a questi documenti come riferimento ufficiale.

Quando aggiorni una regola del server qui, ricordati di:
1. Committare la modifica
2. Postare un avviso nel canale Discord delle regole
3. Aggiornare il pin del canale al nuovo documento
